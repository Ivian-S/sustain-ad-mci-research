# ADNI 数据审计总结：V1–V4

更新：2026-10-30。**审计范围：可行性与候选数据匹配；尚未完成正式队列纳入、医学影像质量控制或训练/测试划分。**

## 1. 数据来源和访问

实验室 ADNI 数据存在 SMB 文件共享，由 Linux 算力服务器通过 CIFS 以只读方式挂载，数据主机无法通过 SSH 直接访问。共享根下的 ADNI 目录包含 `data/`、`processed_data/`、`raw_data/`、`recon_all_new/`。影像模态包括 T1、DTI、fMRI、Amyloid PET、Tau PET，具有 DICOM / NIfTI 目录。临床多来源数据在计算服务器项目内的 `data/all.xlsx`（**受控数据、不入 Git**）。

项目环境详情存在本地 `docs/LOCAL_ENV_PRIVATE.md`。本次数据审计读取范围及日志在 `results/data_audit/`；不要向外部仓库发布受试者级数据、路径索引、影像或原始 Excel。

## 4. V3 日期匹配（已完整读表，但仍属候选队列）

`09_matched_feasibility_v3.json`：**12,758 行完整读取**；T1 元数据的 3,237 个 PTID 中 3,221 个具有注册表映射；具有可解析日期和 image ID 的 T1 影像元数据记录总计 12,758 行。按每人**最早满足条件的 T1 扫描**，同时配对附近诊断与至少一项认知量表：**1,830 人**。

匹配策略：诊断 T1 ±180 天、认知 T1 ±90 天、Amyloid T1 ±365 天；认知随访以 MRI 日期与可用的认知基线之间较晚者为预测起点；约12、24月随访容差均 ±180 天，正式预测应更严格或者显式采用实际随访时间。

| 临床分类 | T1＋诊断＋任一认知 | 基线 MMSE | 基线 ADAS13 | MMSE 至少6月以后随访 | MMSE 约12月 | MMSE 约24月 | T1 附近 Amyloid 状态记录（未解码） |
|---|---:|---:|---:|---:|---:|---:|---:|
| CU | 788 | 692 | 440 | 515 | 268 | 276 | 197 |
| MCI | 765 | 697 | 545 | 539 | 416 | 269 | 151 |
| Dementia | 277 | 255 | 206 | 156 | 121 | 54 | 56 |
| 合计 | 1,830 | 1,644 | 1,191 | 1,210 | 805 | 599 | 404 |

**易混淆处：** 各列不是相同人的完全交集：例如 765 名 MCI、697 名基线 MMSE、539 名 6 月后 MMSE 不能简单判定所有 539 名都拥有网络可用、经 QC 的 T1。此处统计为“候选合格元数据”而非已确认实体影像。

**Amyloid：** V3 全表 `AMYLOID_STATUS_UCBERKELEY` 记录值有 numeric 0 共 1,500 条、numeric 1 共 1,214 条；这是**记录数**且编码未经当前数据字典核实；不能拿它们当作阴/阳性人数，也不能把 Aβ 状态直接写进论文纳入标准。

## 5. V4 磁盘实际文件存在性检查（重要的部分阳性证据）

V4 Excel 读取 12,758 行，识别 3,237 个 T1 元数据 PTID 和 12,333 个 T1 影像 ID。扫描结果：

| 扫描根目录 | 扫描条目数 | 发现完整 FS `.stats` 三件套目录 | 与 Excel 相交的不同 PTID | 是否完整 |
|---|---:|---:|---:|---|
| `processed_data` | 280,115 | **821** | **444** | 否 |
| `recon_all_new` | 369 | 0 | 0 | 否，几乎未深入 |
| `data/T1_nii` | 2 | NIfTI 0 | PTID / Image ID 0 | 否，几乎未深入 |

`processed_data` 的 821 个目录还发现 `mri/norm.mgz`、`mri/aparc+aseg.mgz`、`surf/lh.white` 等文件（各 821 个目录）。这是**可复用预处理成果的强信号**，但不等于完成 FreeSurfer QC；444 不应解读为 CU/MCI 各多少或所有人有认知随访。

**技术陷阱：V4 使用全局 deadline，共享给 `processed_data`、`recon_all_new`、`T1_nii`。由于第一项耗去绝大多数时限，后两项未得到有效扫描。** 因此 V4 的零值**不能当作影像缺失证据，也不能将 V4 视作所有文件的完整匹配**。此前 V1 曾在 `recon_all_new` 看到 `.stats` 数千个，更说明零值是扫描覆盖问题。

## 6. 审计结论（可用于开题；不可误写进实验结果）

**已经足以支持：**
- 选题以 ADNI、T1、FreeSurfer 脑区形态 + 个体 MSN、SuStaIn、认知量表为核心，数据来源和临床随访覆盖具有合理可行性。
- MCI 以及 CU 作为主要临床分组候选；在导师许可后引入基线认知共同输入 SuStaIn，并用**独立后续**认知变化验证。
- 脑网络从现有 T1/FreeSurfer 多形态特征构建，避免 DTI 工程量作为首选路线（需导师认可）。

**仍不能支持：**
- 真实合格 T1／MSN 网络与 1,830 或 765 的完全相交人数；训练集/测试集规模；最终高质量 A+ 样本数；数据一定能产生显著发现；某种网络异常真实领先认知下降若干年。

## 7. 正式实验前的最小收尾检查（不再进行盲目全盘扫描）

1. 在本地对 `processed_data` 已见 PTID 与 V3 临床队列做 **RID/PTID + 影像访视日期 + FreeSurfer 完整目录** 的定向相交；统计 CU、MCI、Dementia、基线认知及 ≥6/12/24 月随访 **最终可用交集**。仅导出汇总，不导出个人明细。
2. 对 10–20 名覆盖 CU/MCI 的候选对象手动/脚本抽查 `aseg.stats`、`lh/rh.aparc.stats`、`mri/*`、`surf/*` 是否可读、有无 eTIV、皮层厚度与面积等特征；抽样 MRI 影像及分割 QC，标明失败原因。
3. 若需更多 T1/FS，针对单独 `recon_all_new`、`T1_nii` 限定文件后缀/目录结构分开扫描；不可用一份扫描时间预算横跨三个大型目录。
4. 在研究方案中单独说明 ADNI 各阶段诊断代码、0/1 Amyloid 状态、示踪剂和 QC 的数据字典确认路径。
5. 按病人划分训练/验证/测试，所有标准化、协变量校正、SuStaIn 模型拟合在训练数据内完成；同一患者所有访视放在同一划分中。
