# PROJECT_CONTEXT — 长期研究背景与决策记录

> 用途：跨对话、跨研究阶段保留经过确认的事实、研究假设和决策。

## 1. 已确认的信息

- **培养方向**：山东师范大学，计算机技术专业硕士研究生。
- **导师给定的核心主题**：围绕临床前期 AD 和 MCI 人群，将脑结构/网络损伤的潜在演变模式与临床认知/行为变化联系起来，探索早期风险识别。
- **主要候选方法**：Subtype and Stage Inference（SuStaIn）。
- **项目目标**：完成选题论证、开题报告、算法实现与验证、硕士学位论文。
- **计算条件**：Linux 服务器；4 × NVIDIA RTX 3090、48 线程 CPU、充足存储。
- **数据状况**：实验室拥有相关数据，但数据类型、规模、使用许可、纵向随访等尚未核实。
- **协作方式**：本仓库存放持续性研究记录；服务器/Codex 辅助开发；聊天助手协助文献、方案与代码审查。

## 2. 研究范围与术语边界

- AD：阿尔茨海默病；MCI：轻度认知障碍，**并非所有 MCI 都由 AD 引起**。
- 临床前期 AD：应尽可能由合适的 AD 生物标志物界定，不能简单等同“认知正常”。
- SuStaIn：根据观测的生物标志物分布推断疾病亚型与潜在进展阶段；**横断面事件顺序不能直接解释为真实时间间隔或因果先后**。
- “早期诊断”“预测未来认知下降”的表述与实验主张，须由实际数据、研究设计和验证结果支持。

## 3. 暂拟研究问题（均未最终确定）

- **RQ1**：MRI 脑区形态特征可否支持稳定、可解释的 AD/MCI 异常亚型与阶段推断？
- **RQ2**：脑网络指标是否在传统 MRI 脑区特征之外带来可靠的信息增益？
- **RQ3**：保留 SuStaIn 亚型–阶段后验概率，能否改善纵向认知评分/进展风险预测？

**暂定论文题目（待导师确认）**：基于 SuStaIn 的阿尔茨海默病早期脑结构异常演变建模与认知功能下降预测研究。

这只是可行性探索方向；研究假设不是已取得的创新成果。

## 4. 计划中的技术路线（待数据确认）

1. 文献调研：SuStaIn、AD/MCI 异质性、脑网络与纵向认知预测。
2. 数据审计：获取合法使用权限；确认 MRI 类型、诊断、生物标志物、认知评分、随访时间与缺失情况。
3. 基线方法：在获授权数据上复现 pySuStaIn；记录亚型、阶段、稳定性和可解释性。
4. 可选网络模块：依据原始影像和图构建条件决定是否纳入 SSN/连接组特征。
5. 可选预测模块：纵向数据充足时，评估 SuStaIn 后验概率驱动的认知轨迹预测。
6. 实验验证：患者级数据划分、严格时点控制、基线对比、消融及不确定性报告。
