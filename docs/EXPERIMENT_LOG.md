## 3. 防止研究设计失效的检查项

- [ ] 先定义任务、预测时间起点和临床标签，再建立模型
- [ ] 同一患者的所有访视不跨越训练/验证/测试划分
- [ ] 特征提取、补缺、标准化、批次效应校正等不使用测试集信息
- [ ] 预测未来认知评分时，不能使用预测时点之后才获得的特征
- [ ] 检查 SuStaIn 的建模输入是否包含被用作独立验证的认知量表
- [ ] 纵向研究正确处理访视间隔、失访与删失
- [ ] 亚型数量、超参数和最终模型不得根据测试集反复挑选
- [ ] 有基线模型、可靠性分析与失败实验记录
- [ ] 上传前确认结果仅为允许发布的汇总数据
