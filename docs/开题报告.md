## 1. 项目概览

### 1.1 研究主题

以临床认知功能正常（Cognitively Unimpaired，CU）和轻度认知障碍（Mild Cognitive Impairment，MCI）人群为主要研究对象，利用 ADNI 数据库中的基线 T1 加权结构 MRI、FreeSurfer 脑区形态指标和同期认知评分：

1. 建立脑区形态学 SuStaIn 基线模型。
2. 基于多维脑区形态指标构建**个体脑形态相似性网络**（Morphometric Similarity Network，MSN）。
3. 将形态学、MSN 拓扑和基线认知指标按不同组合输入 SuStaIn，推断潜在亚型、阶段及异常事件顺序。
4. 使用**基线之后的独立认知随访数据**检验模型结果与未来认知变化的关联和增量价值。

本研究**不以提出新的 SuStaIn 基础算法为目标**；重点在于网络表征的可复现构建、多类信息的受控比较，以及独立纵向验证。

### 1.2 核心研究问题

| 编号 | 研究问题 | 主要检验内容 |
| --- | --- | --- |
| RQ1 | 个体 MSN 是否提供传统脑区形态特征之外的增量信息？ | 网络特征的稳定性、异常方向、对亚型/阶段/事件顺序的影响及独立临床关联 |
| RQ2 | 脑形态、网络拓扑与认知损害呈现怎样的联合异常模式？ | 各潜在亚型中的相对事件顺序；控制特征数量、尺度与冗余后的结果稳定性 |
| RQ3 | 联合模型是否更好地关联后续认知变化？ | M1–M4 在相同队列、相同独立随访结局上的纵向关联及增量价值 |

### 1.3 研究范围及重要概念边界

- **主要分析人群**：临床 CU、MCI。
- **痴呆阶段个体**：仅在样本和设计允许时用于严重程度辅助建模或敏感性分析；主要临床解释仍针对 CU/MCI。
- **Aβ 阳性亚组**：只有在生物标志物编码、匹配及质量控制确认后才开展条件性分析。
- **不能直接等同**：未经 Aβ 等生物标志物确认的 CU ≠ 临床前期 AD；全部 MCI ≠ AD 所致 MCI。
- **MSN 边的含义**：脑区间多维形态特征的相似程度，**不是**真实白质纤维连接，也不等于 dMRI 纤维连接强度。
- **SuStaIn 阶段/顺序的含义**：模型基于横断面数据推断的潜在相对异常事件顺序，**不等于**经过直接观察证实的真实时间进展过程。
- **评价原则**：既要评价模型的稳定性和临床关联，也要允许“不存在显著增量价值”的结果。

## 2. 研究背景与方法依据（精简）

阿尔茨海默病（Alzheimer's Disease，AD）及相关认知障碍具有显著异质性。不同个体的脑结构损伤部位、异常模式及认知功能变化并不完全一致，传统诊断分组或少量脑区指标不足以完整描述这些差异。MCI 个体在随访中可能进展、稳定或改善，且 MCI 并非必然由 AD 病理引起。

T1 MRI 和 FreeSurfer 可提供脑区体积、皮层厚度、面积、曲率等形态学指标。个体 MSN 以每名受试者各脑区的多维形态特征为基础，可从跨区域形态相似性的角度补充局部脑区指标。SuStaIn（Subtype and Stage Inference）利用生物标志物异常模式，同时推断潜在进展亚型与相对阶段；本项目拟主要使用 **pySuStaIn 的 Z-score SuStaIn** 实现。

已有研究分别支持脑区形态学 SuStaIn、个体脑形态网络、影像与认知联合建模及纵向认知验证的可行性。但不同研究使用的网络定义、特征组合和评价策略不相同，尚需针对本项目的 T1-only MSN 检验：

- 网络指标是否稳定，并具有可解释的疾病相关异常方向；
- MSN 与其来源的形态特征高度相关时，是否真正产生额外信息；
- 不同数量和尺度的输入事件会怎样影响 SuStaIn 模型；
- 推断的亚型/阶段能否关联**独立于建模输入**的未来认知变化。

## 4. 总体技术路线与实施顺序

完整处理链：

```text
ADNI 数据核验与基线配对
    ↓
T1 MRI / FreeSurfer 质量控制
    ↓
提取脑区形态学指标
    ├──→ M1：形态学 SuStaIn 基线
    └──→ 构建个体 T1-only MSN → 提取网络拓扑指标
              ↓
基线认知指标核对、方向统一及特征筛选
              ↓
M1 / M2 / M3 / M4：SuStaIn 受控建模
              ↓
亚型、阶段、事件顺序与模型不确定性分析
              ↓
基线之后的独立纵向认知验证
              ↓
稳定性 / 消融 / 敏感性 / 条件性亚组分析
```

**优先执行顺序：先完成 M1，再构建 MSN，然后执行 M2–M4，最后完成独立随访验证。** 如果后续环节出现技术或数据问题，仍应保留可信的形态学基线结果。

## 5. 实验步骤与方法细节

### 5.1 实验 A：精确匹配、纳入与质量控制

**拟执行：**

1. 根据受试者唯一标识（RID/PTID）、影像检查标识、实际 T1 扫描日期和临床访视日期关联各数据来源。
2. 核对诊断字段、认知量表的合法取值及评分方向。
3. 检查 MRI 文件可用性、FreeSurfer 基础 `.stats` 文件完整性、脑区分割质量与候选特征缺失程度。
4. 每名受试者原则上使用满足条件的较早 T1 检查作为研究基线。
5. 首先针对 **10–20 例**开展 FreeSurfer 与临床配对及分割质量抽查。
6. 建立经质量控制的受试者纳入清单，再确认正式 CU/MCI 队列及随访覆盖。

**数据划分及防泄漏规则：**

- 按**受试者**分割训练集与测试集，不按访视记录随机分割；同一受试者的任何访视都不能跨集合。
- 仅使用各受试者在基线时已经可获得的信息拟合基线模型。
- 缺失值处理、协变量回归、标准化、异常方向设定及特征筛选均在**训练集内**拟合。
- 将训练集学到的固定变换应用于验证集/测试集。
- 构建 Z-score 异常评分的参考分布时，优先考虑**训练数据中的临床 CU 参考人群**。
- 不使用未来随访信息决定基线特征、标准化参数或基线分型结果。

**当前状态：**候选队列和文件存在性审计已开展；精确影像对应、完整 QC 和正式样本规模尚待确认。

### 5.2 实验 B：脑区形态学特征提取

**输入：**通过 QC 的 T1 MRI 及 FreeSurfer 结果。

**候选特征：**

- 脑区体积（Volume）。
- 皮层厚度（Cortical Thickness）。
- 表面积（Area）。
- 曲率（Curvature）。
- 必要时保留其他具有一致定义、覆盖良好的 FreeSurfer 形态指标。

**处理原则：**

1. 从 `aseg.stats` 和左右半球 `aparc.stats` 等文件提取区域指标，构成受试者 × 脑区/特征的基础矩阵。
2. 核查不同脑区的指标定义是否一致，以及数据是否足够完整。
3. 形态学 SuStaIn 可保留合适的皮层下区域指标；**不能**因某些皮层下区域缺少足够多维指标，就强行把它们作为 MSN 多特征节点。
4. 统一特征的疾病相关异常方向；协变量校正、缺失处理及标准化的拟合范围遵守训练集规则。
5. 记录特征名称、来源文件、单位、异常方向和筛选依据。

### 5.3 实验 C：个体 T1-only MSN 网络构建

**定义：**对每一名受试者，将每个皮层脑区表示为一个多维形态学特征向量，再根据脑区间向量相似性构建该受试者的**加权邻接矩阵**。

**拟执行流程：**

1. 确定在各皮层脑区之间具有一致定义和充分覆盖的多维形态特征集。
2. 对区域形态特征执行统一、可复现的标准化流程。
3. 对每名受试者计算各脑区特征向量之间的相似度；初步考虑**相关性相似度**。
4. 明确负边权处理、网络稀疏化/阈值、图密度及加权路径距离转换规则。
5. 从网络中提取少量有合理解释且可靠的图拓扑指标，初步关注：
   - 全局效率（Global Efficiency）；
   - 局部效率（Local Efficiency）；
   - 必要的少数节点级或其他全局指标。
6. 针对相似度度量、特征集、阈值、图密度及路径变换开展敏感性分析。
7. 对候选网络指标检查可靠性、疾病相关异常方向、潜在非单调性及与原始脑区形态特征的冗余。

**关键限制：**

- 仅有单一体积指标的区域，不得直接套用要求多维输入的 MSN 定义。
- 相似性网络不是 dMRI 连接组。
- 强非单调、不稳定或难以赋予合理进展方向的网络指标，不直接放入 SuStaIn 异常事件序列。
- **MSN 构建的最终标准化方式、负边规则、稀疏化参数、图密度及入模网络指标数量均未在原方案中定稿。**

### 5.4 实验 D：Z-score SuStaIn 建模

**主要实现：**pySuStaIn 中的 Z-score SuStaIn。

**拟执行：**

1. 基于训练数据中的参考分布和经核查的异常方向构建 Z-score 异常特征。
2. 选择具备合理进展含义的候选输入；根据数据与模型要求设定、检查异常事件阈值。
3. 对网络图指标重点检查方向、稳定性和与进展相关的单调性假设。
4. 开展多次随机初始化、候选亚型数量比较和交叉验证，以评估适当模型复杂度。
5. 输出潜在亚型、阶段、异常事件顺序以及事件位置不确定性。
6. 使用**位置方差图（Positional Variance Diagram）**展示不同事件在推断顺序中的不确定程度。
7. 记录训练样本、特征版本、参数、随机种子、软件版本及实验日志。

**需要强调：**SuStaIn 推断的事件顺序是模型化的相对顺序，不能将横断面推断直接写成已经证实的纵向因果过程。

### 5.5 实验 E：四组模型的受控比较

| 模型 | 输入特征 | 主要目的 |
| --- | --- | --- |
| **M1** | 脑区形态学特征 | 建立基础形态异常的分型/分期参照 |
| **M2** | 脑区形态学 ＋ 个体 MSN 拓扑指标 | 检验网络表征的额外作用 |
| **M3** | 脑区形态学 ＋ 基线认知指标 | 分析影像与认知的联合异常模式 |
| **M4** | 脑区形态学 ＋ MSN ＋ 基线认知指标 | 对三类信息进行受控联合建模 |

**公平对照要求：**

- 四组模型尽量使用**相同且可比较的研究队列**与预先确定的评价方案。
- 控制输入特征的数量、尺度、异常方向、相关性和冗余，避免某类特征仅因事件数更多就占据主导。
- 特别注意：MSN 指标从形态指标派生，两者并非统计独立。
- 不直接用**原始似然、未归一化的阶段编号、事件序列长度**评判跨模型优劣。
- 不同模型的阶段范围由输入事件数量和阈值定义决定；例如“阶段 5”在 M1 和 M4 中未必具有相同含义。
- 重点比较模型稳定性、在相同未来临床终点上的关联及增量作用。

## 6. 独立纵向认知验证与统计分析

### 6.1 主要结局

优先使用基线之后真实采集的 **MMSE、ADAS13 或 CDR-SB** 认知评估记录。关注：

- 随时间变化的认知水平及变化趋势；
- 相对于基线的认知变化量；
- 调整基线认知水平后，不同亚型/阶段与未来认知变化的关联。

**正式模型使用真实时间间隔**，而不是把可行性审计中的“约 12 个月/24 个月”宽窗口当成精确的实验标签。

### 6.2 纵向关联分析

当随访间隔不一致时，拟优先使用**线性混合效应模型（Linear Mixed-Effects Model）**，分析：

- 基线推断的 SuStaIn 亚型；
- 基线推断的 SuStaIn 阶段；
- 上述分型/分期与随访时间的交互效应；
- 年龄、性别、受教育年限、基线认知水平等必要调整变量。

应报告效应估计及置信区间，并明确比较对象、受试者数量和有效观测次数。

### 6.3 避免基线认知循环验证

**高优先级约束：**

M3、M4 已将部分**基线认知评分**作为 SuStaIn 的输入。因此：

- 不得把“模型阶段与同一次基线认知评分相关”作为预测有效的主要证据。
- 验证应以**未来新测量的独立记录**、相对基线变化或调整基线评分后的认知变化速度为依据。
- 若某认知量表既用于基线输入又用于未来验证，必须在时间和统计设计上明确区分。
- 不得让随访信息进入训练时的特征选择、预处理或标签构建。

### 6.4 可选的个体预测扩展

只有在有效配对样本量足够、设计允许时才开展预测实验。若执行，拟使用相同的受试者级训练/测试划分，对照：

1. 人口学变量＋基线认知；
2. 脑区形态相关输入；
3. SuStaIn 亚型/阶段表征；
4. 联合模型表征。

预测结果拟报告 **MAE、RMSE 和校准情况**。如果有效随访样本不足，应优先完成可信的纵向关联分析，不强行宣称预测性能或临床预测能力。

## 7. 稳定性、消融与敏感性分析

### 7.1 MSN 网络层面

- 多维区域形态特征的组成及覆盖差异；
- 特征标准化方案；
- 相似性度量选择；
- 负边处理；
- 图稀疏化阈值和图密度；
- 加权最短路径/距离转换方式；
- 网络指标的可靠性、异常方向与单调性。

### 7.2 SuStaIn 层面

- 随机初始化及重复运行；
- 候选亚型数量；
- 交叉验证与受试者级重抽样；
- 输入特征数量、尺度和相关性；
- 异常事件阈值与事件顺序的不确定性。

### 7.3 研究设计层面

- M1–M4 在**相同样本**上的消融和临床比较；
- MSN 相对于基础形态学的增量；
- 基线认知的额外作用及可能的信息冗余；
- 有条件开展 Aβ 阳性亚组分析；
- 阴性结果、非稳健结果或模型假设不满足时，如实报告，不强行选择“显著”结果。

## 8. 研究难点、风险与应对策略

| 风险/难点 | 已知原因 | 拟采取的措施 |
| --- | --- | --- |
| 候选样本与实际可用样本差距较大 | ADNI 多来源记录复杂；T1、FreeSurfer 和认知访视并非天然一一对应 | 基于扫描日期和检查标识进行精确匹配，抽查 10–20 例，建立最终 QC 清单 |
| FreeSurfer 脑区指标不一致 | 不同脑区特征覆盖、分割质量和定义不同 | 核查指标定义和完整性；形态学特征与 MSN 节点分别确定纳入范围 |
| MSN 参数影响较大 | 负边、阈值、图密度和路径距离变换可能改变拓扑指标 | 预先规定规则并实施多参数敏感性检验 |
| MSN 网络指标不满足 SuStaIn 假设 | 部分拓扑指标可能非单调或异常方向不明确 | 使用临床梯度和合理的方法依据筛除不合适的指标 |
| 联合输入存在共线性 | MSN 由形态指标派生；认知指标之间也可能冗余 | 限制并平衡特征数量，在同一队列与独立终点上开展消融比较 |
| 跨模型比较不公平 | 输入事件维度不同，阶段编号无法直接对应 | 不按原始似然或原始阶段号简单排名，采用共同的临床终点和稳健性证据 |
| 随访时间不规则 | 访视间隔不一致 | 使用实际时间与线性混合效应等纵向方法 |
| 数据泄漏与循环验证 | 同一人多访视、基线认知兼作模型输入 | 受试者级分组；预处理仅在训练集拟合；M3/M4 使用未来独立结局 |
| 有效随访过少 | 影像和认知的真实交集可能较小 | 先完成纵向关联，样本不足时不做过度预测解释 |

## 10. 给后续 AI 使用的工作约束

在基于此文档执行实验辅助任务时，遵守以下规则：

1. **区分事实与计划**：已完成的是数据覆盖与候选审计，不是完整的 QC 后建模结果。
2. **先核对数据再建模**：不得将 T1 元数据匹配、FreeSurfer 文件存在性或宽表随访覆盖误认为实际可用于联合实验的样本数。
3. **保护实验公平性**：M1–M4 尽量使用相同的可比较队列和独立临床评价数据。
4. **严格防止泄漏**：受试者级拆分、训练集内拟合预处理、基线与未来随访隔离。
5. **检查建模假设**：尤其是网络指标的异常方向、可靠性和单调性。
6. **尊重网络定义**：MSN 表示形态相似性，不是物理纤维连接。
7. **避免循环论证**：M3/M4 的同次基线认知输入不构成独立预测有效性证据。
8. **不要跨模型直接比较原始阶段号**，也不以原始似然或事件数量简单确定“最优模型”。
9. **遇到未明确的参数，先列为待确认项**；不要编造数据、实验效果或已完成的结论。
10. **结果可复现与数据合规优先**：记录参数及软件版本，不上传患者级数据、身份索引或访问凭据。
