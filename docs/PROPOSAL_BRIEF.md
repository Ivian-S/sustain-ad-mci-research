# 开题报告写作前的研究方案说明（供接手 AI 使用）

版本：2026-10-30。**这不是已获导师批准的开题报告，不得将规划性创新点或未完成实验写成已验证结论。**

## 1. 选题身份

暂定题目：**《基于 SuStaIn 的 AD/MCI 脑结构网络与认知功能联合演变建模研究》**。

专业：计算机技术，硕士论文。导师核心要求：以早期 AD／MCI 为对象，分析脑结构或网络损伤的潜在模式/异常顺序以及与临床认知行为下降的对应关系，采用 SuStaIn。用户主要目标是稳妥完成开题、实验与毕业论文；目前尚无明确已完成的研究模型结果。

论文主题不应被包装成“已经实现临床早期诊断”；如没有独立诊断金标准、前瞻性验证和指标支持，使用“早期进展建模”“认知变化关联及风险分层”更恰当。

## 2. 研究目标（可直接扩写）

（1）构建 ADNI 目标人群的 T1 脑区形态表征及个体脑形态相似性网络表征，并评估网络指标与脑形态异常的关系。

（2）利用 SuStaIn 分别建立形态、形态＋网络、形态＋认知、形态＋网络＋认知四类亚型/阶段推断模型，比较不同信息组合下的事件序列及分型一致性。

（3）在受试者级严格划分与独立随访认知记录中评价所得潜在亚型/阶段对未来认知变化的解释或预测价值；研究不同人群亚组、特征集及图构建参数下的稳健性。

（4）在 QC、数据字典及样本量允许的条件下，研究 Aβ 阳性早期 AD/MCI 亚组；如样本不足，则保持临床分组名称，不将不明确 AD 生物学状态的 MCI 直接视作 AD。

## 3. 最小技术路线

**受试者选取/数据质量控制** → 基线 T1/FreeSurfer 形态特征及基线认知、协变量 → **个体** MSN 构建/图指标 → 训练集内参考组调整、异常方向定义、输入特征筛选 → M1–M4 SuStaIn 分型/分期与事件顺序 → 亚型/阶段稳定性分析 → 独立认知终点和真实时间随访分析 → 消融、敏感性及可选风险预测。

具体注意：FreeSurfer `lh.aparc.stats`/`rh.aparc.stats` 可能提供区域厚度、面积、曲率等多个指标；MSN 必须由**每名受试者自己的多维脑区特征向量**构建。若只有脑区体积，不能直接套用多指标 MSN 方案；应先确认支持的形态指标和参考论文的数学定义。个体 MSN 不代表 DTI 纤维追踪。

对网络图特征的异常方向、单调性、尺度与相关性，必须检查，SuStaIn 不适用于任意无单调异常含义的特征直接阈值拼接。脑网络特征和多项认知分量尺度不同，应防止某一模态特征数量多而主导模型；可先限定每类输入特征数量且采用公平消融设计。

## 4. 建议实验矩阵

| 研究任务 | 基线或主要方法 | 输出/指标 | 风险控制 |
|---|---|---|---|
| 数据与参考组 | 按身份＋日期＋文件 QC 筛选；正常参考组 | 纳入流程、缺失率、组别统计 | Aβ 未核实不得宣称 A+ |
| 形态 SuStaIn | M1 | 最优亚型数、PVD、稳定性 | 多次初始化与交叉验证 |
| 结构网络 | 多指标 MSN + 网络指标筛选 | 个体网络、特征分布与可靠性 | 多阈值敏感性；排除高度不稳定指标 |
| 联合分型 | M2、M3、M4 | 模型稳定性、阶段关联、事件顺序 | **同一受试者子集**对照，控制特征数量 |
| 认知纵向 | LMM/分层回归/简单预测基线 | 亚型×时间、效应区间、ΔMMSE/ADAS13/CDRSB | 尽量控制基线认知、年龄、性别、教育等；不用输入的基线评分循环验证 |
| 鲁棒性/消融 | 去网络、去认知、变更图阈值、重复抽样 | 稳定性、效应一致性 | 患者级划分，训练内标准化 |
| 可选增强 | 风险/认知评分预测 | MAE、RMSE、C-index（仅真正定义进展事件时）、校准 | 临床基线对照和留出测试 |

**研究假设（待检验）**：网络增量和联合模型可形成不同的阶段/亚型与认知联系；尚未证明一定改善性能。阴性结果也应按预设检验报告，避免选择性叙述。

## 5. 真实数据已确认的可行性证据

- `all.xlsx` 完整审计：12,758 行、955 列，存在多量表、临床诊断与 T1 元数据。
- V3 日期匹配：CU 788、MCI 765、Dementia 277 名，共 1,830 名 T1 元数据＋临近诊断＋认知候选。MCI 基线 MMSE 697、MMSE 后续至少6个月 539、约12月 416、约24月 269。
- V4 部分盘点在 `processed_data` 中发现 821 个 `.stats` 完整三件套目录，涉及 444 个可与 Excel 编号相交的不同 PTID（未验证这些人的诊断、同次访视或 QC）。V4 后两范围扫描不完整，NIfTI=0 无法解释为不存在影像。
- 数据量、计算服务器与公开 pySuStaIn 实现使基线实验具有实现条件，但尚不能写“模型已验证有效”。

## 6. 可行性及风险预案

- **数据风险**：FreeSurfer 与临床真正同次的 MCI 数量可能低于 V3 元数据规模。方案：优先定向配对后抽查 10–20 例，必要时只对入选 T1 重新进行 FreeSurfer/FastSurfer 处理。
- **方法风险**：个体 MSN 指标不单调、关联方向不稳定。方案：先把形态 SuStaIn 跑通，谨慎挑选图指标并进行图阈值稳健性对照；必要时与导师讨论替代网络定义。
- **临床风险**：临床 MCI 与 A+ MCI 并非同一对象，Amyloid `0/1` 编码尚未核验。方案：研究对象语言精确、对生物学定义的结论只限证据充分亚组。
- **创新风险**：联合 SuStaIn 与认知、网络已有单独或部分组合研究。方案：主张是严谨早期人群场景的三类信息增量比较＋纵向外部于输入的终点，明确方法组合创新强度有限。若导师要求算法层创新，需再设计一个可消融的受限算法改进，不能凭空命名新方法。
- **计算风险**：SuStaIn 多次初始化/交叉验证主要消耗 CPU；GPU 不作为论文复杂度理由。
