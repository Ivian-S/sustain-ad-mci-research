## 1. 项目任务

正式题目：基于 SuStaIn 的 AD/MCI 脑结构网络与认知功能联合演变建模。

用户是计算机技术硕士，首要目标是按期、稳妥完成论文。已确定 T1-only MSN、临床 CU/MCI、Z-score SuStaIn 和未来认知随访验证的研究主线。不再重新开展选题论证，不擅自增加 DTI、PET、深度学习或复杂概率预测模块。

三项研究问题：MSN 能否提供稳定的增量表征；形态/网络/基线认知的联合异常事件模式如何；推断的亚型阶段是否关联未来认知变化、是否具备额外价值。详细实现参见 [实验方案](EXPERIMENT_PLAN.md)。

已知环境：Linux，48 CPU 线程，4×RTX 3090；现有 `sustain-audit` Conda 环境用于审计，不代表 pySuStaIn 已安装。原始 ADNI 数据经 SMB/CIFS 只读挂载，不能直接 SSH 到数据主机；在计算服务器本地工作。临床宽表为本地 `data/all.xlsx`。私人位置说明在本地 `docs/LOCAL_ENV_PRIVATE.md`（禁止提交）；如缺失请用户在本地核对，不要求提供密钥。

以实际服务器状态为准。SuStaIn 主要消耗 CPU；先小规模计时，再选择并行数、迭代与候选亚型数。不要未经批准启动大规模处理、写入原始共享盘或删除数据。

协作流程：
1. 读取本文件、实验方案及审计总结，检查实验日志和当前 Git commit。
2. 查看实际脚本、配置及依赖；先复用现有审计能力，不盲目重写。

5. 每次记录真实命令、版本、配置、随机种子、结果与失败；在阶段结束时更新本文件的状态及下一任务。

## 4. 首次接手应该做什么

先开展 E0.1：确认本地审计 JSON、现有脚本、共享挂载可读性及数据快照；检查 V4 的候选索引是否仍可用。然后按 PTID/RID + Image ID + 实际日期定向匹配 FreeSurfer 与临床。优先抽查 10–20 例 CU/MCI，再制定全量 QC，不重新无目标扫描整个共享盘。

必须先明确身份或访视冲突，不允许仅凭相同 PTID 直接认定同一次检查。输出经审核的汇总统计；所有受试者级中间表留在受控本地目录。E0 验收条件见实验方案。

## 5. 固定约束

- 临床 CU/MCI 不等于生物学确诊 AD；Aβ 编码与 PET QC 未确认，阳性亚组为扩展。
- MSN 是个体多维形态相似性，不是群体协方差或白质纤维连接。
- M1 为成熟方法参照；M2=形态+MSN；M3=形态+基线认知；M4=形态+MSN+基线认知。
- 受试者级划分；所有跨个体拟合的预处理、筛选、参考分布和模型选择限于训练数据。后续认知结局不能参与基线建模。
- 阶段是潜在事件位置，不是真实年月或因果关系；不同模型原始阶段号和似然不可直接比较。
- 独立随访指基线之后未作为模型输入的观测，不等于独立外部队列。预测必须另做受试者级样本外验证。
- 不承诺 M4 优于 M1；阴性及失败结果照实记录。网络核心路线如果不可行，先报告并与导师讨论，不擅自改题。
- 不上传患者级数据、内部路径、索引、原始输出、凭据或受限制论文。数据使用与公开许可问题需按实际协议确认。
